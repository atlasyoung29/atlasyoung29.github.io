# atlasyoung29.github.io

Source for the site published at <https://atlasyoung29.github.io/>.

## Build

There is no build step. The site is a single static `index.html` plus four
images in `assets/`. It has no dependencies, no framework, and makes no
external network requests — the page loads nothing beyond the files in this
repository. The only JavaScript is a small IntersectionObserver that reveals
sections on scroll.

Open `index.html` in a browser to preview it. GitHub Pages serves the
repository root, so a push to `main` publishes.
