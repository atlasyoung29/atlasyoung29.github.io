Research

Rust market maker for Polymarket's maker-reward program, which pays for resting tight two-sided quotes on binary markets. It ranks reward-eligible markets, sizes every quote to depth it can actually hedge, and exits each fill the cheaper way. The README is a post-mortem: getting flat means crossing the book, and the crossing costs more than the reward pays — hedged is not the same as profitable.

Built with @gabrielsalazar777 · not run as a live earner
