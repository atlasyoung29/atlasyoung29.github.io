01agent-orchestration

Architecture write-up

Two AI coding agents, each running on a different model, split by job rather than by subject. Claude Opus 5 handles messages, documentation and reviewing commits. GPT-5.6 Luna handles iOS builds and anything long-running. One writes the work, the other tries to break it, and the claim that survives stands.

  • Context windows are ephemeral: durable memory is a linked-Markdown Obsidian vault, read at session start.
  • One hub note per folder, parent-to-child links only — no sibling edges, so the graph stays navigable.
  • A push hook reviews each commit's diff against the docs and writes them back in sync.

Tradeoffs · Documents a working setup rather than packaging it as a framework — the patterns port, the wiring doesn't.

02SpreadEater

Research · Rust · TypeScript · Polymarket CLOB · EIP-712 · Axum

Rust market maker for Polymarket's maker-reward program, which pays for resting tight two-sided quotes on binary markets. It ranks reward-eligible markets, sizes every quote to depth it can actually hedge, and exits each fill the cheaper way. The README is a post-mortem. The resting legs earned their spread, but the hedge leg is a taker order by construction — every fill pays a crossing, and the crossing costs more than the reward program pays. That inequality is structural, not a tuning problem.

  • Markets are ranked by reward per share before anything is quoted.
  • Quote size is capped at the depth it can actually hedge.
  • Each fill exits the cheaper way — on-chain pair merge or the bid book.

Tradeoffs · Scoped as research, not a live earner — the post-mortem is the deliverable.

03Lore

Swift · SwiftUI · SwiftData · MapKit · Python

iOS travel companion: it reverse-geocodes your exact spot and returns a sourced debrief with walkable pins. Trusting generated output is the hard part — every pin the model proposes is snapped onto a real POI coordinate or dropped, enforced once on the backend and again in the app.

  • Pins are dropped, not approximated, when no real POI coordinate matches.
  • The same coordinate check runs twice — once server-side, once in the app.
  • Sources travel with the debrief, so a generated claim can be checked.

Tradeoffs · Held at prototype scope on purpose — the coordinate and sourcing guarantees come before feature breadth.

SwiftUI app + dependency-free stdlib Python backend · typed JSON contract, so a deterministic mock swaps in · path-gated CI on both halves

04PolyScanner V2

Live · Python · Flask · NumPy · SwiftUI

Turns Polymarket's public trade feed — unreadable by eye — into statistically significant datapoints. Every trade is scored against a rolling baseline for that market and outcome, so "large" is relative to the market, not a dollar cutoff, and flagged trades are grouped by wallet to surface one hand moving across several markets at once.

  • Baselines roll forward with the feed rather than sitting at a fixed threshold.
  • Cards expand to position, payout, z-score, wallet and transaction hash.
  • Grouping by wallet turns scattered flags into one actor's activity.

Live dashboard · free-tier host sleeps when idle — first load takes ~30s to wake · Native SwiftUI companion app on the same public API
